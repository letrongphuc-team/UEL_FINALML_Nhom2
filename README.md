HairCare Insight is a Machine Learning project in the hair care product business domain, developed to help businesses utilize customer and sales data more effectively. The system focuses on three main functions: identifying customers’ hair care needs and recommending suitable products based on a Hair Quiz, segmenting customers using RFM analysis combined with the K-Means clustering algorithm, and forecasting product sales quantities for upcoming weeks. By integrating Machine Learning models into the system, the project aims to support personalized customer experiences while providing valuable data-driven insights for business analysis and planning.
